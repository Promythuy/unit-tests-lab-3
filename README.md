## Опис функції

Функція `loyalty_points(amount, is_member)` обчислює бали лояльності за покупку:

- 1 бал за кожні повні 20 грн.
- Учасники програми (`is_member=True`) отримують подвійні бали (×2).
- Якщо сума від'ємна (`amount < 0`), виникає помилка `ValueError`.

## Інструкція з запуску та покриття

1. Установка залежностей:

```bash
pip install -r requirements.txt
```

2. Запуск юніт-тестів:

```bash
pytest
```

3. Генерація звіту про покриття (Coverage):

```bash
pytest --cov=loyalty --cov-report=term-missing
```
